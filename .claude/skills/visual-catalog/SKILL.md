# 시각 자료 카탈로그

차트·도식을 **처음부터 그리지 않는다.** 이미 있는 것을 먼저 훑고, 사용자가 고른 뒤에 만든다.

## 절대 원칙 셋

**1) 후보를 내밀기 전에 만들지 않는다.**
"차트 만들어줘"에 바로 코드를 쓰지 말고 **후보 3개를 제시**한다. 취향은 내가 정할 것이 아니다.

**2) 남의 코드를 그대로 붙일 수 있는지 먼저 따진다.**
카탈로그의 컴포넌트는 대부분 **React**다. 이 저장소의 렌더러는 **Playwright + HTML/CSS/SVG** 라
**코드는 못 쓰고 디자인 규격만 옮길 수 있다.** 이걸 먼저 말하고 시작한다.

**3) "이 기법을 쓰면 좋아진다"를 재보지 않고 말하지 않는다.**
적용 전후를 실측해 숫자로 낸다. 재보니 두 곳이 오히려 나빠져 통째로 버린 사례가 있다
→ `references/transfer-notes.md`.

---

## 절차

### 0. 무엇을 어디에 만드는지 정한다

| 물을 것 | 왜 |
|---|---|
| 무엇을 보여주나 | 시계열·비교·구성비·분포·관계 — 종류가 그림을 정한다 |
| 어디에 들어가나 | 차트 노트 카드(1080×1350) · 브리핑 카드 · 릴스(1080×1920) · 문서 |
| 정지인가 움직이나 | 움직이면 감속 곡선·카운트업을 같이 봐야 한다 |

### 1. 이 저장소가 이미 가진 것부터 본다 ← 대부분 여기서 끝난다

**차트 노트 작업이면 `references/chartnotes-types.md` 를 먼저 읽는다.**
«이번 주제 → 어떤 카드 타입» 대응표가 있다. 거기 있으면 밖을 볼 필요가 없다.

절차서가 못 박아 둔 문장이다:

> **"타입을 새로 만들 일은 거의 없다."** `lines` 하나가 이동평균선·골든크로스·지지저항·추세선·
> VIX·볼린저밴드·배당락을 다 그리고, `bars` 하나가 시가총액·PER·PBR·EPS·ROE 를 다 그린다.
> **주제가 바뀌어도 바뀌는 것은 숫자와 라벨이지 타입이 아니다.**

### 2. 이미 연결된 도구로 되는 일인가 본다

`references/catalog-tools.md` 를 읽는다. **이 환경에 실제로 있는 것만** 적혀 있다.

> ⚠️ **차트 노트 카드는 `render-chartnotes.mjs` 로만 만든다.** 외부 도구는 «후보를 탐색하고
> 규격을 참고하는» 용도이지 **산출물을 만드는 용도가 아니다.** Canva·Gamma 로 카드를 만들면
> 시리즈 아이덴티티(크림 모눈 노트·감청색 헤더·붉은 포인트)가 깨진다.

### 3. 그래도 없으면 외부 카탈로그에서 후보를 고른다

`references/catalog-sites.md` 를 읽는다. 사이트마다 **무엇이 있나 / 무료인가 / 무슨 프레임워크인가**가 적혀 있다.

### 4. 후보 3개를 사용자에게 제시한다

```
후보 ① <이름>   <어디서>   <왜 이 주제에 맞나>
후보 ② ...
후보 ③ ...

이 저장소 렌더러는 HTML/SVG 이므로
  · 규격만 옮길 수 있다 → 전부
  · 코드를 그대로 쓸 수 있는 것 → 없음 (React 컴포넌트라서)
```

### 5. 고른 것을 옮긴다

`references/transfer-notes.md` 의 실패 사례를 먼저 읽는다.
**옮긴 뒤에는 적용 전/후를 실측해 숫자로 낸다.**

### 6. 카탈로그를 갱신한다 ← 이 스킬의 목적

- 새 서식 사이트를 알게 되면 → `catalog-sites.md` 에 한 줄. **직접 열어 보고** 라이선스·비용·프레임워크를 같이 적는다
- 새 도구가 붙으면 → `catalog-tools.md` 에 한 줄
- 그림 때문에 실패했으면 → `transfer-notes.md` 에 기록

**사이트마다 스킬을 새로 만들지 않는다.** 이 스킬 하나에 계속 쌓는다.

## 하지 말 것

- 확인 안 한 사이트를 목록에 올리는 것 — 직접 열어 보고, 못 열면 **"확인 실패"라고 적는다**
- 카탈로그에 있다는 이유로 라이선스를 안 보는 것
- 개선 효과를 재지 않고 말하는 것
- **카드 타입 표를 이 스킬에 복사해 오는 것** — 아래 참고

> **주제→타입 대응**만 갖는다. 표를 두 곳에 두면 반드시 어긋난다 — 실제로 이 스킬의 첫 초안이
