**갱신 2026-08-31.** 근거: `content/chart-notes/*.json` 의 **실제 발행 기록**.

> **카드 타입의 정본은 `ROUTINE_PROMPT_CHARTNOTES.md` §5 의 표다.**
> 이 파일은 그 표를 복사하지 않는다. 타입이 몇 종인지, 각 타입이 어떤 필드를 받는지,
> 캔들 색·강조 규칙이 무엇인지는 **절차서를 본다.** 여기 있는 것은 «이번 주제에 무엇을 쓸까»뿐이다.

## 실제 제작 기록 — 여기서 고른다

발행된 회차가 실제로 쓴 구성이다. **새 주제를 만나면 성격이 가장 가까운 줄을 찾는다.**

| 회차 | 주제 | 본문 카드 구성 | 표지 `overlay` |
|---|---|---|---|
| EP.01 | 캔들차트 | (사람이 만든 카드를 받아 씀) | — |
| EP.02 | 이동평균선 | `formula` → `checklist` → `lines` → `lines` | `ma` |
| EP.03 | 골든크로스 & 데드크로스 | `checklist` → `lines` → `bars` → `lines` | `cross` |
| EP.04 | 거래량 | `pricevol` → `checklist` → `formula` → `pricevol` → `versus` | `volume` |
| EP.05 | 지지선과 저항선 | `checklist` → `lines` → `flip` → `pricevol` | `levels` |

**모든 회차가 공유하는 뼈대**: `cover` → (도입) → … → `numbered` → `recap`.
`intro` 는 도입 카드, `numbered` 는 «초보가 흔히 하는 실수 3가지», `recap` 은 3줄 요약이다.

## 주제 → 타입

| 주제 성격 | 쓸 타입 | 표지 `overlay` |
|---|---|---|
| 캔들 하나를 뜯어보기 | `example` · `anatomy` | (없음) |
| 캔들 여러 개를 실제 시세로 | `pricevol` | (없음) |
| 이동평균선 · 추세선 | `lines` | `ma` |
| 두 선이 만나는 것 (골든크로스·데드크로스·MACD·볼린저밴드) | `lines` + `marker` | `cross` |
| **거래량 · 거래대금** | **`pricevol`** — `bars` 아님 | `volume` |
| 가격이 자꾸 멈춘 높이 (지지선·저항선·박스권) | `lines` + `levels`/`touches` | `levels` |
| 뚫린 선의 역할이 뒤집히는 것 | **`flip`** | `levels` |
| VIX · 배당락 · 52주 밴드 | `lines` (+ `band`) | 주제에 맞게 |
| 종목·업종 간 순위 비교 (시가총액·PER·PBR·EPS·ROE) | `bars` | (없음) |
| 나눗셈 하나로 끝나는 지표 | `formula` | — |
| 개념 A 대 개념 B (세는 단위가 다른 둘) | `versus` | — |
| 상승 캔들 vs 하락 캔들 | `compare` | — |
| 용어 여러 개 나열 | `checklist` (+ `figure`) | — |

**표지 `overlay` 는 주석(`annot`)이 가리키는 대상이 실제로 그려지는 값을 고른다.**
EP.03 이 `ma`(선 하나)인데 주석은 "두 선이 만나는 순간"이라 **가리킬 교차점이 없었다**(검증에서 적발).

## 흔한 잘못 — 실제로 겪은 것

| 잘못 | 무슨 일이 있었나 | 올바른 선택 |
|---|---|---|
| 거래량을 `bars` 로 | EP.04 초안이 거래량을 가로 막대로 그렸다가 *"막대그래프 얘기인지 거래량 얘기인지 모르겠다"* 는 지적을 받고 통째로 다시 만듦 (이슈 #21) | **`pricevol`.** 가격과 나란히 봐야 하는 것은 전부 `pricevol`. `bars` 는 종목 간 비교 전용 |
| 같은 값을 두 이름으로 맞댐 | EP.04 비교 카드가 «거래량»과 «주식 수»를 나란히 놓았는데 같은 값이라 혼란만 남음 (이슈 #23) | `versus` 의 두 축은 **정말 다른 것**이어야 한다 |
| 도입 스케치를 안 고름 | EP.02·03·05 의 p.02 가 **픽셀 단위로 같은 그림**이었다 (이슈 #25) | `intro.sketch` 를 회차마다 고른다. 없으면 새로 추가 |
| 그림이 글을 배반 | EP.05 제목이 «가로선»을 묻는데 그림에 가로선이 없었다. p.04 꺾은선이 자기 지지선을 5번 중 3번 빗나감 | 카드 문구가 가리키는 것이 **화면에 실제로 있는지** 렌더 후 눈으로 확인 |
