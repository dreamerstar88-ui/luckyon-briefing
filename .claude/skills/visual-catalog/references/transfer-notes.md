## 1. 규격 문서가 있다고 차트 규격이 있는 건 아니다 (2026-08-30)

**무엇을 했나** — Monocharts 에 `.agents/skills/amicro-design-system/SKILL.md` 가 있는 것을 보고
"차트 규격을 여기서 가져오면 된다"는 계획을 냈다.

**무엇이 틀렸나** — 열어 보니 목차가 이랬다.

```
1. 디자인 토큰과 팔레트          ← 일부만 쓸 수 있음
2. 표준 카드 구조                 ← Amicro 웹사이트 카탈로그 카드
3. 카탈로그 내비게이션·필터 알약   ← 웹사이트 UI
4. 마이크로 인터랙션·햅틱          ← 브라우저 진동 API
5. CLI 레지스트리 등록 규칙        ← 그 저장소에 컴포넌트 추가하는 법
```

**차트를 어떻게 그리는지는 없다.** 차트 규격은 각 `.tsx` 파일 안에 흩어져 있었다.

**교훈** — **파일을 열기 전에 계획을 내지 않는다.** 목차만 봐도 30초면 알 수 있었다.

## 2. `tabular-nums` 는 절반짜리 처방이었다 (2026-08-30)

**무엇을 했나** — 릴스의 카운트업 숫자가 흔들린다고 보고, `tabular-nums`(숫자 폭 고정)를 처방했다.

**먼저 확인한 것 — 이건 잘했다**

Canvas 2D 에는 `font-variant-numeric` 이 **없다.** 그래서 폰트 자체를 재 봤다.

```
Pretendard Bold 100px 숫자 폭 실측
  0:66.0  1:46.9  2:61.0  3:63.9  4:65.7  5:62.7  6:64.3  7:57.5  8:64.4  9:64.3
  최소 46.9px  최대 66.0px  차이 19.1px (29.0%)
```

고정폭이 아니었다. **흔들림은 실재했다.**

**그런데 효과를 재 보니** (SPY 1배 5.2초 카운트업, 실측)

| 자리 | 항목 | 현재 | 폭 고정 후 | |
|---|---|---|---|---|
| 평가액 (오른쪽 정렬) | 프레임 간 최대 변동 | 42.3px | **42.3px** | **변화 없음** |
| 배수 (가운데 정렬) | 프레임 간 최대 변동 | 47.1px | **53.2px** | **악화** |
| 요약표 6행 | 자릿수 열 어긋남 | 26.1px | 17.1px | 34.5% 개선 |

**가운데 정렬이 나빠지는 이유** — `1` 이 가장 좁은데(46.9px 대 66.0px) 폭을 고정하면
`1` 도 넓은 칸을 차지한다. `1.0배` → `11.3배` 처럼 `1` 이 늘어나는 구간에서 더 크게 벌어진다.

**원인을 분해했더니**

| 흔들림의 출처 | 크기 | 폭 고정으로 잡히나 |
|---|---|---|
| **자릿수가 늘어날 때** (`$99,999` → `$100,000`) | **42.3px** | **못 잡는다** |
| 자릿수 같은데 숫자만 바뀔 때 | 34.9px | 잡힌다 → 0 |

**큰 쪽이 못 잡는 쪽이었다.**

### 자리 예약을 시도했다 — 그리고 **재는 대상을 틀렸다**

최종 자릿수만큼 앞을 빈칸으로 채우고 그 빈칸도 숫자 한 칸 폭으로 세는 방법을 만들었다.
재 보니 **0.0px** 이 나와 "완전히 해결됐다"고 보고했다.

**틀렸다.** 그 0.0px 은 **예약한 상자의 폭**이었다. 눈에 보이는 것은 상자가 아니라 **글자**다.
**오른쪽 정렬에서는 상자를 아무리 예약해도 글자가 그려지는 좌표가 안 바뀐다.**

### 글자 끝 이동 거리로 다시 잰 결과 — 실제 서체 기준

`render-backtest-reel.mjs` 가 쓰는 실제 서체(`x(104)` · `sb(34)` · `x(148)`)로 다시 쟀다.

| 자리 | 정렬 | 그대로 | 폭 고정 | 폭 고정 + 자리 예약 |
|---|---|---|---|---|
| 평가액 `:566` | 오른쪽 | 왼쪽 **67.2px** | 왼쪽 **70.9px** ↑ | 왼쪽 70.9px (변화 없음) |
| 원금의 N배 `:569` | 오른쪽 | 왼쪽 **16.0px** | 왼쪽 **22.0px** ↑ | 왼쪽 22.0px (변화 없음) |
| 배수 `:731` | 가운데 | 양쪽 **39.5px** | 양쪽 **50.4px** ↑ | 왼쪽 **100.9px** / 오른쪽 0.0px |

**세 곳 모두, 세 방식 모두 나아지지 않았다. 대부분 나빠졌다.**

- 오른쪽 정렬: 자리 예약은 **글자를 안 움직인다.** 상자 폭만 일정해진다
- 가운데 정렬: "양쪽이 조금씩" 이 "한쪽이 크게(100.9px)" 로 바뀔 뿐이다
- `1` 이 많이 나오는 구간에서는 폭 고정이 **오히려 나쁘다** (`1` 에 넓은 칸을 주므로)

**최종 결론: 적용하지 않는다.** → `backtest-reels/docs/숫자 흔들림 조사 — 2026-08-30.md`

**교훈 넷**
1. **무엇을 재는지 먼저 정한다.** "상자 폭"과 "글자 위치"를 혼동해 틀린 결론을 냈다
2. **"기법을 적용하면 좋아진다"를 재지 않고 말하지 않는다.** 세 곳 중 두 곳이 나빠졌다
3. 개선이 안 되면 **원인을 분해한다.** 진짜 원인은 자릿수 증가였고, 그건 막을 수도 막아서도 안 된다
4. 카탈로그의 기법이 **내 환경에 맞는다는 보장이 없다.** Amicro 는 React·CSS 이고 여기는 캔버스다.
   `font-variant-numeric` 자체가 Canvas 2D 규격에 없다

### 구현

`amicro-sample/scripts/lib/tabular.mjs` 에 있다.

| 함수 | 하는 일 |
|---|---|
| `digitPitch(ctx, font)` | 그 서체·크기에서 가장 넓은 숫자의 폭 |
| `tabularWidth(ctx, text, font)` | 폭 고정으로 그렸을 때의 전체 폭 |
| `fillTabular(ctx, text, x, y, font, align)` | 폭 고정으로 그린다 |
| `reservedWidth(ctx, text, font, slots)` | 자리 예약까지 넣은 폭 |
| `fillReserved(ctx, text, x, y, font, slots, align)` | **폭 고정 + 자리 예약으로 그린다** |

`slots` 는 그 구간에서 나올 **가장 긴 표기의 길이**를 넣는다.
예: 최종값이 `$113,351` 이면 `slots = 8`.

## 3. 재현할 때는 원본 좌표를 그대로 읽는다 (2026-08-30)

A/B 비교를 만들 때 "현재" 쪽을 대충 만들면 **허수아비를 때리는 것**이 된다.
원본에서 정확한 줄 번호와 값을 읽어 왔다.

```
render-backtest-reel.mjs:566  ctx.fillText(usd(head.v), W-72, 369)   평가액, 오른쪽 정렬, b(46)
                        :731  ctr(ctx, L.runMultiple(...), P.runY, x(P.runSize))  배수, 가운데 정렬
                        :829  ctx.fillText(v, W-112, y)              요약표 값, 오른쪽 정렬, b(46)
                        :509  head = { v: a0.v + (a1.v-a0.v)*frac }  ← 매 프레임 보간. 진짜 카운트업이다
```

**`head.v` 가 보간된다는 것을 확인하고 나서야** 흔들림이 실재한다고 말할 수 있었다.

## 4. 캔버스 렌더러를 만들 때 자주 나오는 결함

첫 렌더에서 실제로 나왔던 것들. **프레임을 뽑아 눈으로 보기 전에는 "완성"이라고 하지 않는다.**

| 결함 | 원인 | 조치 |
|---|---|---|
| 축 라벨이 화면 밖으로 잘림 | 차트 바깥 오른쪽정렬인데 `$100K` 가 `$10K` 보다 넓어 좌표가 음수 | 라벨을 차트 **안쪽**으로 |
| 아래 패널이 위 내용을 덮음 | 두 블록의 y 범위가 겹침 | 뒤 장면이 시작되기 전에 앞 블록을 **사라지게** |
| 마지막 줄이 하단 출처와 겹침 | 블록 전체가 너무 아래에서 시작 | 블록을 위로 올리고 줄 간격 조정 |

확인 명령:
```bash
ffmpeg -ss <초> -i out/x.mp4 -frames:v 1 -vf scale=540:-1 out/chk.png
```

## 5. 쓰지 말아야 할 도구

| 하려던 것 | 왜 안 되나 | 대신 |
|---|---|---|
| Bash 히어독으로 긴 `.mjs` 작성 | **중간에서 잘렸다.** 175줄짜리가 문자열 도중에 끊김 | **Write 도구**를 쓴다 |
| `npm run dev` 를 Bash 로 | 서버 실행은 막혀 있다 | `preview_start` + `.claude/launch.json` |
| launch.json 에 `npm` 지정 | 경로에 공백이 있어 `'C:\Program' 을 찾을 수 없음` | `node` 로 `node_modules/vite/bin/vite.js` 직접 |
| vite 에 `--root` | vite 6+ 에서 **root 는 위치 인자**다 | `node vite.js <경로> --port <포트>` |
