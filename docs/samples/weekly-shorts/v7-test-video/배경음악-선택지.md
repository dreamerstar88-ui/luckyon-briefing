# 배경음악을 어디서 만들 것인가 — 확인한 것 전부

2026-09-08 이 세션에서 실제로 확인한 결과다. 추측이 아니라 도구를 불러본 기록이다.

## 결론

**Suno 는 이 세션에 붙일 수 없다.** Claude 커넥터 목록에 Suno 가 없다.
대신 **TopView 로 곡을 만드는 데 성공했다.** 다만 만든 파일을 이 세션으로 내려받는 것은
회사 egress 정책에 막혀서, 대표가 링크로 직접 받아야 한다.

## 1. Suno — 왜 안 되는가

| 확인한 것 | 결과 |
|---|---|
| 설치된 커넥터 49개 전체 조회 | Suno 없음 |
| 커넥터 레지스트리 검색 (`suno`, `music generation`, `AI song` 등) | Suno 없음. Tella·Viberate 만 나옴 |
| Zapier 앱 9,000개 검색 (`Suno`) | 없음. BDOW(FKA Sumo)·Runo CRM 만 나옴 |

대표가 2026-08-23 에 쓰신 Suno MCP 는 **커넥터가 아니었다.**
`배경음악/제작 스크립트/사용한 도구.md` 에 직접 "커넥터 | 없음, MCP 서버 | Suno MCP" 라고
적어 두셨다. 즉 **대표 컴퓨터의 Claude Code 에 MCP 서버로 등록**해 두신 것이다.

클라우드 세션은 대표 컴퓨터의 로컬 프로세스에 닿을 수 없다. 그래서 이 세션에서는 못 쓴다.

### 클라우드에서 쓰려면

그 Suno MCP 가 **원격 서버(https 주소)** 여야 한다. 그렇다면 두 가지 길이 있다.

1. **claude.ai → 설정 → 커넥터 → 사용자 지정 커넥터 추가**에 그 서버 주소를 넣는다.
   그 다음 이 대화의 커넥터 설정에서 켜면 세션 도구 목록에 들어온다.
2. 저장소 루트에 `.mcp.json` 을 두고 원격 서버를 적는다. 프로젝트 범위 MCP 설정이라
   같은 저장소로 열리는 세션이 함께 읽는다.

어느 쪽이든 **그 Suno MCP 서버의 주소와 API 키가 필요하다.** 대표 컴퓨터의
Claude Code MCP 설정에 있다. 로컬 실행형(stdio)이면 클라우드에서는 어떤 방법으로도 안 된다.

주의: Suno 는 공식 MCP 를 내지 않았다. 쓰신 것은 제3자가 만든 서버일 가능성이 높다.
계정·크레딧·약관을 한 번 확인하시는 편이 좋다.

## 2. TopView — 지금 되는 길 (실제로 만들어 봤다)

TopView 커넥터가 이미 연결돼 있고 크레딧이 9.2 남아 있었다. 곡 하나에 **1 크레딧**.

```
모델: Topview Music (또는 Minimax Music 2.6)
instrumental: true
styles: dark cinematic synth, minimal electronic, tense but restrained,
        steady pulse, 100 BPM, A minor, no vocals,
        financial data documentary background,
        subtle build with a turn at 22 seconds, clean low end, not busy
```

생성 성공. 결과 링크: **https://api.topview.ai/s/2MzKSDTb**

**다만 이 세션에서 파일을 내려받지 못했다.** `api.topview.ai` 와 원본 CloudFront 주소
둘 다 프록시가 403 으로 막았다(조직 egress 정책). 정책 거부는 우회하지 않는 것이 원칙이라
거기서 멈췄다. 대표가 위 링크를 브라우저로 열어 mp3 를 받으신 뒤 아래 명령으로 넣으면 된다.

```bash
FF=node_modules/ffmpeg-static/ffmpeg
$FF -y -i 받은파일.mp3 -af "afade=t=in:st=0:d=1.0,afade=t=out:st=28.2:d=1.8,\
   loudnorm=I=-14:TP=-1.5:LRA=11" -ar 48000 -ac 2 -t 30 bgm30.wav
$FF -y -i "reel_nasdaq-week_30s_무음.mp4" -i bgm30.wav -map 0:v:0 -map 1:a:0 \
   -c:v copy -c:a aac -b:a 192k -ar 48000 -ac 2 -shortest -movflags +faststart 완성.mp4
```

곡이 30초보다 길면 `-ss <시작초>` 를 앞에 붙여 원하는 구간을 자른다.

## 3. ElevenLabs — 권한만 열면 된다

ElevenLabs 커넥터는 연결돼 있지만 음악·영상 생성 도구가 **Flows 권한**을 요구하는데
지금 연결에는 그 권한이 없다(403 insufficient_permissions).

커넥터 설정에서 ElevenLabs 를 **다시 연결**하고, 권한 화면에서 **Flows 를 승인**하면
이 세션에서 바로 음악을 만들 수 있다. 그래도 거부되면 ElevenLabs 워크스페이스 관리자가
역할 권한을 줘야 한다.

## 4. 기존 기준 음원 (가장 확실)

`sj-park-investment-backtest/backtest-reels/배경음악/기준-배경음악3.wav` (58.4초, Suno 원곡).
대표 컴퓨터에 있다. 시리즈 소리가 일관되고 이미 검증된 곡이다.

```bash
$FF -y -ss 28.4 -i "배경음악/기준-배경음악3.wav" \
   -af "afade=t=in:st=0:d=1.0,afade=t=out:st=28.2:d=1.8,loudnorm=I=-14:TP=-1.5:LRA=11" \
   -ar 48000 -ac 2 -t 30 bgm30.wav
```

뒤쪽 30초를 쓰면 고조 구간이 영상 끝에 온다.

## 권장 순서

1. TopView 곡을 받아서 들어 보고 마음에 들면 그걸로 (링크는 위에)
2. 아니면 기존 기준 음원 뒤쪽 30초
3. 계속 새로 만들 거면 ElevenLabs 재연결(Flows 승인)이 가장 손이 덜 간다
4. Suno 를 고집한다면 원격 MCP 서버 주소를 확보해 사용자 지정 커넥터로 등록

지금 영상에 들어간 소리는 `music.mjs` 가 합성한 임시 판이다. 위 넷 중 하나로 바꾸는 것을 권한다.
